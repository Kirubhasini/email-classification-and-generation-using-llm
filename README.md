# Email Classification and Generation using LLM

## Overview
This project is an AI-powered email assistant that classifies emails into different categories and automatically generates professional email replies using Large Language Models (LLMs).

The system helps users manage business emails efficiently by reducing manual effort and improving response quality.

## Features
- Email classification (Urgent, Normal, Irrelevant)
- AI-based email reply generation
- Customizable generated responses
- Dashboard for viewing classified emails
- NLP-based preprocessing
- Machine Learning integration

## Technologies Used
- Python
- Flask
- Cohere API / LLM
- Machine Learning
- HTML, CSS
- JSON / CSV datasets

## Project Workflow
1. Load email dataset
2. Preprocess email text
3. Classify emails using ML model
4. Generate replies using LLM
5. Display editable responses
6. Save customized replies

## Applications
- Business email automation
- Customer support systems
- Smart email management
- AI-powered communication systems
